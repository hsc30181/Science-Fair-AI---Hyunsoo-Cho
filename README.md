# Science-Fair-AI---Hyunsoo-Cho

Welcome to my Science Fair Project!
In the project, I'll test the accuracy of the prediction made by Image Prediction AI models that are each trained with 50, 100, 150 images for each object.
The models are trained using a service called Teachable Machine and tested by app.py (You can find it in this repository). Any kind of generative AI model (ChatGPT, Gemini Claude .etc) was not used in this project. I also remind you that there's a license attached in the repository that will prevent you from plagiarism.
